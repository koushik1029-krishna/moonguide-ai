Application Description

MoonGuide AI is a local educational prototype for Moon’s Food Store. Guests ask about approved sample hours, location, products, services, and EBT/SNAP. Answers come only from server/data/knowledge.json. Unsupported questions fall back to an employee. Restricted-sale and ID questions escalate; the assistant does not approve a sale or replace a legally required ID check. Guest, Staff, and Manager views share in-browser chat and feedback. The manager gate is classroom demo PIN 1234 checked in the frontend, not a server secret and not Amazon Cognito (MoonGuide AI, 2026).
